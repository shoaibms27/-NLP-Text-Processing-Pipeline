# Text Analytics Pro 🧠

A production-ready NLP application for text analysis and feature extraction using Streamlit and scikit-learn.

## Features ✨
- **Advanced Text Processing**: Automatic cleaning, lemmatization, and stopword removal
- **Vectorization Methods**:
  - Bag of Words (BoW) representation
  - TF-IDF with IDF scores visualization
- **Customizable Parameters**:
  - Adjustable n-gram ranges (1-3)
  - Feature limit controls (50-500 features)
- **Data Insights**:
  - Interactive feature matrix visualization
  - Sortable IDF scores table
- **Export Capabilities**: CSV download functionality

## Installation ⚙️

streamlit run app.py
